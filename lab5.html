Теоретичні відомості

Пошук — це процес знаходження елемента в масиві або іншій структурі даних. У лабораторній роботі розглядаються: - лінійний пошук; - бінарний пошук.

Лінійний пошук

Лінійний пошук послідовно перевіряє всі елементи масиву, поки не знайде потрібний. Асимптотична складність: O(n)

def linear_search(arr, target):

    for i in range(len(arr)):

        if arr[i] == target:
            return i

    return -1


arr = [3, 7, 2, 9, 5]

print(linear_search(arr, 9))

Бінарний пошук

Бінарний пошук працює лише для відсортованого масиву.

Алгоритм: 1. знаходить середній елемент; 2. порівнює його з шуканим; 3. відкидає половину масиву.

Асимптотична складність: O(log n)

def binary_search(arr, target):

    left = 0
    right = len(arr) - 1

    while left <= right:

        mid = (left + right) // 2

        if arr[mid] == target:
            return mid

        elif arr[mid] < target:
            left = mid + 1

        else:
            right = mid - 1

    return -1

arr = [1, 2, 3, 5, 7, 9]

print(binary_search(arr, 7))

Дослідження часу виконання

import random
import time
import pandas as pd
def linear_search_test(sizes):

    result = []

    for n in sizes:

        arr = list(range(n))

        target = random.randint(0, n - 1)

        start = time.perf_counter()

        linear_search(arr, target)

        end = time.perf_counter()

        result.append([n, end - start])

    return pd.DataFrame(result, columns=["n", "time"])
def binary_search_test(sizes):

    result = []

    for n in sizes:

        arr = list(range(n))

        target = random.randint(0, n - 1)

        start = time.perf_counter()

        binary_search(arr, target)

        end = time.perf_counter()

        result.append([n, end - start])

    return pd.DataFrame(result, columns=["n", "time"])
sizes = [10, 100, 1000, 5000, 10000, 50000]

linear_df = linear_search_test(sizes)

binary_df = binary_search_test(sizes)

print(linear_df)

print(binary_df)

Висновок

Лінійний пошук має складність O(n), тому час його роботи швидко зростає при збільшенні розміру масиву.

Бінарний пошук має складність O(log n), тому працює значно швидше на великих масивах.

Найефективнішим є бінарний пошук, але він потребує попереднього сортування масиву.

Контрольні питання

  1. Задача пошуку полягає у знаходженні елемента в масиві або іншій структурі даних.

  2. Для оцінювання ефективності використовують:

  • час виконання;
  • використання пам’яті;
  • асимптотичну складність.

  1. Лінійний пошук — це послідовний перегляд елементів масиву. Його складність: O(n)

  2. Бінарний пошук — це алгоритм пошуку у відсортованому масиві, який кожного кроку ділить область пошуку навпіл.

  3. Переваги бінарного пошуку:

  • висока швидкість;
  • складність O(log n).

Недолік: - працює лише з відсортованими даними.
