Теоретичні відомості

Стек — це структура даних, що працює за принципом LIFO (Last In First Out). Основні операції: - push — додавання елемента; - pop — видалення верхнього елемента; - peek — перегляд верхнього елемента.

class Stack:

    def __init__(self):
        self.items = []

    def isEmpty(self):
        return self.items == []

    def push(self, item):
        self.items.append(item)

    def pop(self):
        return self.items.pop()

    def size(self):
        return len(self.items)
s = Stack()

s.push(10)
s.push(20)
s.push(30)

print(s.items)

print(s.pop())

print(s.items)

Функція pop_n()

Функція видаляє елементи стека від початку до номера n включно.

def pop_n(stack, n):

    for i in range(n + 1):

        if not stack.isEmpty():
            stack.pop()


s = Stack()

s.push(1)
s.push(2)
s.push(3)
s.push(4)

pop_n(s, 1)

print(s.items)

Асимптотична складність стека

  • search: O(n)

  • insert (push): O(1)

  • delete (pop): O(1)

Черга

Черга — це структура даних, що працює за принципом FIFO (First In First Out).

class Queue:

    def __init__(self):
        self.items = []

    def isEmpty(self):
        return self.items == []

    def enqueue(self, item):
        self.items.insert(0, item)

    def dequeue(self):
        return self.items.pop()

    def size(self):
        return len(self.items)
q = Queue()
q.enqueue(10)
q.enqueue(20)
q.enqueue(30)

print(q.items)

print(q.dequeue())

print(q.items)

Функція print_n()

Функція друкує елементи черги від початку до номера n включно.

def print_n(queue, n):

    for i in range(min(n + 1, queue.size())):

        print(queue.items[-(i + 1)])

q = Queue()
q.enqueue(1)
q.enqueue(2)
q.enqueue(3)
q.enqueue(4)
print_n(q, 2)

Асимптотична складність черги

  • search: O(n)

  • insert (enqueue): O(n)

  • delete (dequeue): O(1)

Контрольні питання

  1. Стек — це структура даних типу LIFO. Основні операції: push, pop, peek.

  2. Основна відмінність полягає у принципі роботи:

  • стек — LIFO;
  • черга — FIFO.
  1. Стек можна реалізувати:
  • за допомогою масиву;
  • за допомогою зв’язаного списку.

Масив простіший у реалізації, а зв’язаний список ефективніший при великій кількості змін.

  1. Застосування:
  • стек: рекурсія, історія браузера, скасування дій;
  • черга: обробка задач, принтери, сервери.
