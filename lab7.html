Дерева

Дерево — це структура даних, що складається з вузлів, пов’язаних між собою. Кожне дерево має: - корінь; - піддерева; - листки.

def BinaryTree(r):

    return [r, [], []]


def insertLeft(root, newBranch):

    t = root.pop(1)

    if len(t) > 1:
        root.insert(1, [newBranch, t, []])

    else:
        root.insert(1, [newBranch, [], []])

    return root


def insertRight(root, newBranch):

    t = root.pop(2)

    if len(t) > 1:
        root.insert(2, [newBranch, [], t])

    else:
        root.insert(2, [newBranch, [], []])

    return root
r = BinaryTree(10)

insertLeft(r, 5)

insertRight(r, 15)

print(r)
[10, [5, [], []], [15, [], []]]

Видалення гілки дерева

def deleteLeft(root):

    root[1] = []

    return root


deleteLeft(r)

print(r)
[10, [], [15, [], []]]

Асимптотична складність дерева

  • search: O(log n)

  • insert: O(log n)

  • delete: O(log n)

Купа

Купа — це бінарне дерево, у якому: - у max-heap батьківський елемент більший за дочірні; - у min-heap батьківський елемент менший за дочірні.

heap = [0]

def parent(i):
    return i // 2

def insert(elem):

    heap.append(elem)

    index = len(heap) - 1

    while index > 1 and heap[parent(index)] < heap[index]:

        heap[parent(index)], heap[index] = \
        heap[index], heap[parent(index)]

        index = parent(index)
import random

arr = [random.randint(1, 100) for _ in range(10)]

print(arr)

for x in arr:
    insert(x)

print(heap)
[14, 28, 67, 57, 41, 80, 24, 32, 80, 87]
[0, 87, 80, 67, 57, 80, 28, 24, 14, 32, 41]
insert(7)

print(heap)
[0, 87, 80, 67, 57, 80, 28, 24, 14, 32, 41, 7]

Асимптотична складність купи

  • search: O(n)

  • insert: O(log n)

  • delete: O(log n)

Геш-таблиця

Геш-таблиця — це структура даних для зберігання пар ключ-значення.

class HashTable:

    def __init__(self, size):

        self.size = size

        self.table = [[] for _ in range(size)]


    def hash_function(self, key):

        return hash(key) % self.size


    def insert(self, key, value):

        index = self.hash_function(key)

        self.table[index].append((key, value))


    def search(self, key):

        index = self.hash_function(key)

        for k, v in self.table[index]:

            if k == key:
                return v

        return None


    def delete(self, key):

        index = self.hash_function(key)

        for i, (k, v) in enumerate(self.table[index]):

            if k == key:

                del self.table[index][i]

                return
h = HashTable(10)

h.insert(1, "Denys")

h.insert(2, "Python")

print(h.search(1))

h.delete(1)

print(h.search(1))
Denys

Контрольні питання

  1. Бінарне дерево пошуку відрізняється тим, що:
  • ліві елементи менші за корінь;
  • праві більші.

  1. Купа підтримує порядок між батьківськими та дочірніми вузлами, а звичайне дерево — ні.

  2. Типи дерев:

  • бінарне дерево;
  • дерево пошуку;
  • AVL-дерево;
  • B-дерево.
  1. Дерева використовуються:
  • у файлових системах;
  • базах даних;
  • пошукових алгоритмах.

  1. Купа організована як бінарне дерево. Додавання та видалення виконуються з перебудовою дерева.

  2. Купи використовують:

  • для пріоритетних черг;
  • сортування Heap Sort;
  • планування задач.
  1. Геш-функція перетворює ключ у індекс масиву, що дозволяє швидко виконувати пошук, вставку та видалення.
